# Simplified language

Write every answer, explanation and summary with the discipline of ASD-STE100
Simplified Technical English, in Spanish or in English — short sentences, one
idea per sentence, active voice, one term per concept and no elegant synonyms.
Use the vocabulary of the domain and of the code, and do not invent new names
for concepts that already have one.

## Language

Talk to me in the language I write in: simplified Spanish when I write in
Spanish, simplified English when I write in English. Text you write into a file
— docs, docstrings, comments, commit messages, PR descriptions — takes the
language the file or the project already uses. Keep technical terms and code
identifiers in their original form.

## Scope

Apply these rules to prose and headings only. Leave code, identifiers, verbatim
quotes, link targets and frontmatter as they are.

# Code comments

When you edit code, do not add comments by default. Add one only when it
explains something the code cannot show — a non-obvious reason, a hidden
constraint, a workaround for an external bug — and never to repeat what the
code does.
